# Security Policy

## Supported Versions

Which versions of the project are currently being supported with security updates.

| Version | Supported          |
|---------| ------------------ |
| latest  | :white_check_mark: |
| <= 1.29 | :x:                |

Our first publication is 1.30. We forked from [nv-i18n](https://github.com/TakahikoKawasaki/nv-i18n/) which last published version 1.29.

## Reporting a Vulnerability

Please submit an [Issue](https://github.com/foundationsedge/nv-i18n/issues) or raise a [PR](https://github.com/foundationsedge/nv-i18n/pulls)

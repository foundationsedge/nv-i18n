Please also review [SustainOSS's Governance Readiness Checklist](https://sustainers.github.io/governance-readiness/)
as preparation for making governance decisions.

## Governance Template

[Governance maintainer](https://github.com/foundationsedge/nv-i18n/blob/master/GOVERNANCE-maintainer.md) supplies
rules for a simple self-selecting council of Maintainers as project governance. It assumes that there is no distinction
between the contributors who create the majority of code and documentation for the project and the group who makes all
decisions for the project. This governance is suitable for small, very unified projects, and is often a good starting
point for project governance. It is based on the Jaeger project's governance.
